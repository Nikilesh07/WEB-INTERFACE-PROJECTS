## Getting Started

Clone the repository:

```bash
git clone https://github.com/Nikilesh07/WEB-INTERFACE-PROJECTS.git
```

Open the project folder:

```bash
cd WEB-INTERFACE-PROJECTS
```

For React/Vite projects, install dependencies and start the development server:

```bash
npm install
npm run dev
```

## Deployment

The projects are deployed using **GitHub Pages** with **GitHub Actions**.

Every push to the `main` branch can trigger the deployment workflow and update the project showcase.

## Purpose

This repository contains projects developed as part of my learning and practice in web interface development. The projects cover basic to intermediate concepts such as components, state management, routing, events, forms, and responsive UI design.
